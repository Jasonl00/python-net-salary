# Python Net Salary Calculator

A Python program that calculates federal tax, state tax, and net salary for multiple employees based on salary and state of residence.

## Features

- Accepts the number of employees to process
- Collects each employee's name, salary, and state
- Uses salary to determine the federal tax rate
- Uses state of residence to determine the state tax rate
- Calculates federal and state taxes
- Calculates each employee's net salary
- Processes multiple employees using a loop

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run:

`python net_salary.py`

Depending on your system, you may need to use:

`python3 net_salary.py`

4. Enter the requested employee information and follow the prompts displayed in the terminal.
